# Syndicate Black Ops

Syndicate Black Ops (SBO) is a multiplayer mod for Half-Life 1

## Install

Download and install from https://sbo.sbotnas.io/

## Build

Docker on Linux builds the Windows and Linux binaries:

```sh
git submodule update --init external/hl1_source_sdk
scripts/build.sh
```

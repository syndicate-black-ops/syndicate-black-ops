// Map compatibility rules, read by the server while a map loads (SBO docs: Map compatibility file).
// A rule removes or sets a key on a custom map that carries the key by accident, so the map plays as it was made.
// One rule per line:
//   <map> <crc32 of the .bsp> drop <classname> <selector> <key>
//   <map> <crc32 of the .bsp> set  <classname> <selector> <key> <value>
// selector: * (every entity of the class), #N (entity N of the map's entity lump, 0 = worldspawn), or a targetname.
// The CRC-32 is of the whole .bsp file (python: zlib.crc32): an updated map no longer matches its entries.

// Material types for every map: the steps, hit sounds and impact effects of each material letter.
// The letters come from Half-Life's sound/materials.txt and materials/textures.txt. Half-Life's letters
// (C M D V G T S W P Y F) and the ladder and wade steps are built in; a block here changes only the keys it
// names. A letter without steps walks like C, a letter without hit sounds is hit like C. A map can change all
// of this for itself in materials/maps/<map>.txt. See the SBO docs: Materials.
//
//   material <letter> { keys }      ladder { step keys }      wade { step keys }      texture "NAME" { fx keys }
//   step_right { "a.wav" "b.wav" }  step_left { ... }  (up to 6 each; one is picked at random per step)
//   walk_volume 0.2  walk_time 400  run_volume 0.5  run_time 300  (time: msec to the next step)  step_skip 0/1
//   hit { "a.wav" ... }  hit_volume 0.9  hit_volume_bar 0.6  hit_attenuation 0.8  hit_sparks 0/1
//   name "grass"
//   fx_* : impact effects (SBO docs: Materials, "Effect keys")
// Sound paths are relative to sound/. A file with an error is not used at all; the console says where it is.
// The new letters use the footsteps and impact effects of CS:CZ Deleted Scenes. Chips and puffs are off with
// cl_effectsdetail 0.
